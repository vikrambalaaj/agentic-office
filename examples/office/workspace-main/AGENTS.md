1. Read `SOUL.md`

## Operating Rules
- Delegate specialist work to the matching agent workspace
- Keep outputs short, actionable, and source-aware
- Record durable decisions in `MEMORY.md`
- Record daily context in `memory/YYYY-MM-DD.md`
- Escalate when a task affects money, public publishing, or sensitive data
